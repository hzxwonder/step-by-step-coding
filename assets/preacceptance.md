- **选择影响**：<不同选择如何改变结果、方案、结论范围或主要成本>

## 使用方式

约定从 Q1 连续编号。实际填写时删除以上占位内容，不照搬问题或数量。已有要求或委托且实测一致时，直接引用用户原话登记，不再次询问。

层级填写“核心”或“体验”，按实际影响判断。先解决核心未决项。原话、来源类型与位置、适用范围记在本地确认记录中。启动授权和 Agent 提案不能作为需求确认来源。

直接约定用不带 `--choice` 的 `answer-precheck` 记录，并提供 `--source-kind`、`--source-ref` 和 `--scope`。仍有疑问时使用 `--needs-discussion`。只有使用了实际选项的条目才需要 `--choice A/B/C/D`。

用户原话与判断依据保存到本地 `preacceptance-results.md` 和状态中。当前约定及证据锁定后，变化须按受影响范围更新。补充讲解不撤销确认。

用户已明确接受当前结果时，直接登记验收。同一句话明确授权下一步时，完成当前步结算后再登记下一步授权。

验收前用 `present-case` 登记已向用户展示的真实 case，引用当前运行证据与展示位置。它是 Agent 的展示记录，不增加一轮用户确认。
