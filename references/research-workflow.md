# 用最小实验推进研究判断

用于科研代码实现、复现、评测和结果分析。先从已有协议与代码接续，以当天形成初步判断为目标。当前步骤只解决一项有助理解或验证核心假说的问题。研究设计与实现记录共享名称或实验编号，不重复维护确认状态。

## 1. 先说清当前问题和已知事实

- 研究问题：想解释或改善什么现象，当前最关键的不确定点是什么。
- 当前假说：哪一种机制或变化可能解释现象，为什么值得验证。
- 已有证据：具体实验、数据和结果入口，适用条件与已知局限。
- 尚待验证：Agent 的建议、直觉或文献推断，标明来源与证据强度。

用户问“你怎么知道”时，指向真实实验或来源。没有证据就写待验证，不能把推荐理由改写成已经测到的效果。若有多个问题，先说明本轮选择哪一个及其原因。

## 2. 设计能改变下一步决定的最小比较

在当前 Notebook 或已有设计中简述实际输入、方法与对照、主指标、判定依据和资源边界，引用有效协议。普通实现由 Agent 决定；只补充会改变当前比较的科学含义、权限或主要成本的未决项。

判断规则在查看本轮结果前约定。例如：方法与基线使用相同样本和指标，比较主要效果，同时检查约定的资源代价。具体阈值与容差根据问题和实际依据决定。支持、不支持和证据不足分别说明下一步选项。

首轮复用有效代码、数据和评测入口，按能看见的研究现象或可执行路径划分步骤。输入、方法、调用与观察可在一步内连起，不按准备操作逐项拆回合。路线采用后先保存本步 Notebook 并给出文件入口；仅在已有环境中补本步短测，随后结束当轮。长任务交付完整手动入口。合成数据用于检查实现或受控机制时，说明支持范围。

理论、数值或分析任务可以使用反例、推导检查或小规模计算形成最小证据，不强行增加训练、排行榜或产品页面。

## 3. 关键实现与公平比较

实现前沿用已采用的方法、对照和指标，只核对会改变本轮结论的计算、输入与条件。模型、设备或服务元数据未知，仅在影响当前比较或真实资源、权限边界时阻断运行。

对照与方法的样本、划分、预处理、评测入口及资源条件按科学设计保持可比。确有差异时说明原因与影响。文献报告值与本机复现值分别标注，不默认具有完全相同的条件。数据用途与调参规则提前约定，避免用最终测试结果反复选择设计。

MVP 小比较只支持其实际样本与条件，按当前问题选择重复次数并说明不确定性；正式实验再满足采用协议的样本、划分、重复与统计要求。保留单次结果及汇总来源，说明评测单位，记录失败、超时与未运行项，不能只保留有利运行。生产工程和完整报告的要求不作为首项科学比较的前置条件。

## 4. 先明确资源，再运行

首项比较明确实际使用的设备与数据、规模、费用或卡时上限和停止条件，沿用已有授权。缺少必要授权时一次给出最小核心比较所需范围。估计注明依据或待测；仅实际影响执行、比较有效性或硬资源边界的未知项需要先解决。已有短测可补充耗时依据；未知耗时不通过自动启动长任务来探测。

预计不超过 60 秒且已授权的单元可短测，一轮自动测试总等待也不超过 60 秒。预计更久或耗时未知的单元只编写，提供手动入口与进度输出，不启动后台任务或等待结果。方法、基线、评测、搜索、重试都计入本轮投入。资源上限、证据已足够或明确失败条件触发时停止，交付现有证据与下一项建议。需要新规模、新方法或新增费用时讨论变化，不自动反复运行到出现正结果。

## 5. 保留能复查的最小证据

保存实际输入、方法与对照、生效配置、原始输出及指标计算入口，使其对应同一次运行；版本、随机设置、设备和耗时按当前解释与复查需要记录。

真实 case 展示一项具体输入如何经过方法或对照，得到输出，再形成指标。保留可核对的原始预测、损失或其他结果与指标计算入口，按任务选用。聚合数字、图和表能追溯到原始运行；预期样例不写入实测结果。

关键单元就近显示真实样本、关键变换、中间输出与进度。运行记录沿用已有工具和原始回包，完整日志外置。成本信息缺失时保留未知并收窄相应主张，不自动否定其它有效观察。默认用简短表格或必要曲线解释结果，有研究交互需求时再提供 HTML 原型。

## 6. 执行、科学判断和验收分别记录

| 判断 | 应说明的内容 |
|---|---|
| 执行与证据有效性 | 代码是否按约定计算，输入与对照是否正确，记录是否完整，哪些部分未验证 |
| 科学判断 | 本次证据支持、不支持或仍无法判断什么，可能解释及其证据强度，结论适用条件 |
| 用户验收 | 用户是否接受当前实现与实验交付，是否要求调整或明确授权下一步 |

科学效果不作为单元测试必须达到的断言。测试检查实现和指标计算，实验检验假说。真实负结果可以验收；实现或评测错误先修复，环境受阻保留未验证状态。

每步保存后用三四行说明当前发现、实际状态、文件／已有网址和下一动作，再结束当轮。解释只补新增信息，图表数字直接引用；下一验证先保留一条建议，采用后再细化。纯文字反馈原位修改 Markdown，保留代码、输出与有效测量，不重复运行或浏览器检查。手动结果缺失时说明待运行入口。
